# 使用事件：记录模式

> 日常的，不必记录；特别的，顺手记；规律的，偶尔校准。

这不是打卡。系统默认认为高频资产今天正常使用；用户只记录**值得记录的使用事件**。

## 三种记录模式

| 模式 | 用户说法 | 谁出现在 Today |
| --- | --- | --- |
| 自动估算 `auto` | 手机、电脑、水杯 | 只展示「已自动估算」，不要求点 |
| 快速记录 `quick` | 相机、行李箱 | 「特别使用」一键 +1，可连点 |
| 批量校准 `batch` | 跑鞋、健身器材 | 可 +1，每月问一次大概几次 |

新建资产时按名称 / 类目 / 频率档位自动判断，详情页可改。消耗品走「用完了」，不进特别使用。

## Today

- 日常资产一行带过
- 「今天有没有特别使用？」最多展示 8 个近期/低频资产
- 连点累加当天次数
- 「其他」可一次勾几件，点完成今天
- 每天建议不超过 3 个特别使用（不强制拦住）
- 对久未记录的快速记录资产问一句「最近有没有用过？」
- 对该校准的资产问「过去 30 天大概用了几次？」
