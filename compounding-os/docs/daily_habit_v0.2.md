# Compounding OS v0.2 · Daily Habit 重构

- 日期：2026-08-17
- 状态：首页与 Daily Loop 已按此方案落地第一刀
- 前提：不继续加资产 CRUD / 金融 / iOS；先补「明天为什么回来」

---

## 诊断（保留）

v0.1 做成了完整的资产计算器：录入 → 算成本 → 看趋势。这些都是低频行为。缺的是：

> 发生变化 → 发现变化 → 得到反馈 → 做一个轻动作 → 明天产生新变化

首页原先回答「我的东西怎么样」，应改成「我最近的生活怎么样」。

---

## 三层产品

| 层 | 问题 | v0.2 |
|---|---|---|
| L1 Accounting | 我拥有多少？ | 资产列表 / 详情为二级 |
| L2 Reflection | 我最近怎么生活？ | **Today、Daily Ritual、Insight、30 天对比** |
| L3 Compounding | 我被带向哪里？ | 无购买连续天数、使用价值释放、人生时间轴（初版） |

原则微调：**不替用户做最终决定，但可以提出值得思考的问题**（Decision Support，不是裁决）。

---

## Daily Loop

```text
打开 → Today → 看见昨天/今天的变化 → 一条 Insight
     → 10 秒点一个动作 → 时间轴多一笔 → 明天
```

用户每天回来是为了看「自己有没有在复利」，不是为了给 MacBook 记账。

---

## 已落地

1. **Today / 今日**：主导航第一项；现值账本不再当首页。
2. **使用价值释放**：大数字是「今天资产替你工作释放的价值」（日均成本的正向表述），并对比昨天。
3. **Daily Ritual**：先选动作，再选对象，写入 `life_events`（使用还会写该资产的 `usage_logged`）。
   - **使用** → 搜索并点选一件具体物理资产
   - **学习** → 点选已有能力，或当场「新建并记录」；能力资产在「资产 → 能力」创建和管理
   - **节省** → 写下少买了什么（可选金额），或点「用已有资产代替新购」
   - **创造** → 写下做出了什么，可选挂到一项能力
   - **清理** → 选资产后选整理 / 用完 / 卖掉丢掉（后两者写入资产事件）
4. **Daily Insight**：规则引擎按日轮换（成本回收、使用率变化、无购买、单次成本等），不复述看板数字。
5. **30 Day**：利用率、日均成本、新购入件数，相对 30 天前。
6. **人生时间轴**：购入 / 用完 / 处置 / 估值 / 校准 + 今日动作。
7. **无购买连续天数**：距上次 `acquired` 的天数。

未做（刻意）：强制「今天用了 MacBook 吗」打卡、人生总分、LLM 文案、金融资产。

## 数据

- 资产事件仍是事实源。
- 新增 `life_events`：与资产解耦的人生事件，支撑 Ritual 与时间轴。
- Insight / 30 日对比：对现有事件按日回放，不另存快照。
