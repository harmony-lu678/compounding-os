# Compounding · 当前版本产品说明

- 产品名：Personal Compounding OS（对外简称 Compounding / 个人账本）
- 版本口径：可自用的 Web MVP（2026-08-17）
- 配套文档：[产品规划 v0.1](./product_plan_v0.1.md) · [架构文档 v0.1](./architecture_v0.1.md)

---

## 1. 这个产品干什么

Compounding 算的不是「花了多少钱」，而是**这笔钱正在以什么速度被消耗、换回了什么**。

记账 App 记的是购买价。本产品把耐用品和消耗品当成可经营的资产：按使用频率、寿命、残值、消耗周期，算出日均成本和单次成本，并把每个数字背后的假设摊开，让你自己改。

一句话：**帮你算清楚东西到底值不值，但不替你决定买不买。**

适合：愿意花一点录入成本、想把「贵不贵」变成「划不划算」的个人用户。数据在自己机器上，可批量导入。

---

## 2. 产品原则（已落地）

1. **估算优先于打卡**：录入时选频率档位即可，不必每次使用都记一笔。
2. **消耗品只记「用完了」**：不记剩余量。
3. **数字都是区间，假设可改**：没有无法溯源的精确值。
4. **只算账，不裁决**：不输出 Buy / Don't Buy。
5. **数据可导入**：支持批量导入事件级 JSON；不提供批量导出。

## 3. 当前已有能力

### 3.1 记一笔（资产录入）

- 底部中间「记一笔」进入全屏录入。
- 耐用品 / 消耗品切换；九宫格类目（电子产品、家具、衣物、洗护等）。
- 名称 + 金额数字键盘 + 日期，类目默认寿命 / 残值 / 频率，创建后可再校准。
- 消耗品可带子类目，用于预估消耗周期。

### 3.2 今日（Daily Habit 首页）

- 问的是「你正在积累什么」，不是「资产值多少」。
- **今日释放价值**：把日均成本说成「资产今天替你工作释放的价值」，并对比昨天。
- **今日发现**：一条非复述数字的 Insight（使用率、无购买、成本回收等）。
- **30 Day**：利用率 / 日均成本 / 新购入，对比 30 天前。
- **Daily Ritual**：使用（选具体资产）/ 学习（选或新建能力）/ 节省 / 创造 / 清理，点完即闭环。
- **补货提醒**：消耗品按预估用完日；日用品（购入 150 天内）按约 90 天周期。到窗口只提醒可补，不替你下单。
- **人生时间轴**：购入、用完、处置、校准与今日动作。
- 详见 [Daily Habit v0.2](./daily_habit_v0.2.md)。

### 3.3 资产列表与筛选

- 全部 / 耐用品 / 消耗品 / **能力** 即时筛选。
- 耐用品、消耗品：类目、购入价、主成本、使用率；按次计费可在列表改「已用次数」。
- **能力资产**：不走折旧。在「资产 → 能力」新建；详情是能力账户（投入时间/金钱、应用、产出），不是星级。
- **规划**挂在资产里（`/plan`），不另开 Tab：更换日历、12/24/36 月更新预算、储备金、类目配置、能力时间分配。

### 3.4 资产详情与校准

详情页展示全部指标，每个数字带假设来源（用户填写 / 类目默认 / 实测）。可做：

| 动作 | 说明 |
|---|---|
| 校准使用次数 | 某段时间内用了几次 |
| 校准使用频率 | 改频率档位 |
| 校准季节性 | 衣物 / 床品一年用几个月 |
| 记录估值 | 按二手行情等覆盖线性折旧 |
| 记录维护/耗材 | 累计进持有成本 |
| 用完了 | 消耗品关闭当前周期，周期变实测 |
| 处置 | 卖出 / 报废 |

事件时间线可回溯购入、校准、维护、估值、用完、处置。

详情同时是 **资产账户**：当前价值、累计投入、使用、已释放、剩余寿命，以及未来计划（继续/升级/出售/更换 + 更换窗口）。系统给窗口，不裁决该不该换。

### 3.5 变化（自我反馈，不是报表）

- Tab 名是「变化」。用户先选一个问题，再选 7天 / 30天 / 90天 / 一年。
- 首页回答三件事：最近发生了什么、为什么、正在变好还是变差。
- **资产状态**：价值 / 使用效率 / 日均成本 三条方向，而不是单看现值。
- **越用越便宜**：单次成本随使用次数下降（Cost Decay）。
- **用起来了吗 / 正在浪费**：使用分层 + 贡献矩阵，点进资产看下一步。
- 事件类型统计（校准了几次）不再放在主路径。

### 3.6 设定

- 类目默认值可编辑：寿命、残值、频率、计费方式，也可加新类目。保存后对新录入资产生效。
- **批量导入** JSON（按 id 跳过已有记录）。**不提供批量导出**。

### 3.7 计算引擎（看不见但在用）

- 耐用品：全周期/已实现日均成本、单次成本、剩余价值、使用率（高/中/低）。
- 消耗品：预估周期 → 首次「用完」后转实测每日成本、单次成本。
- 电子产品/家具等默认按天；衣物/箱包/洗护等默认按次。
- 金额用分（cents）计算，避免浮点误差。

### 3.8 部署与数据

- Web 单用户，self-hosted；可选访问密码（`APP_PASSWORD`）。
- SQLite 本地库；种子脚本可导入一批真实资产用于自用。
- REST `/api/v1`：资产、事件、看板、登录、设定、导入。

## 4. 当前版本明确没有的

相对规划里的后续期，**现在还没有**：

- 金融资产、目标系统、决策对比表、AI 周报
- 多用户、iOS / 自动化捕获（账单、NFC、Screen Time）
- 邮件周报、强制逐次打卡、剩余量管理
- Buy / Don't Buy 建议

旧的四象限散点不再当首页。贡献矩阵在「变化 → 哪些东西正在浪费」里，点进资产看下一步。

## 5. 怎么用（最短路径）

1. 打开账本，看现值和日均成本。
2. 「记一笔」录入几件真实耐用品 / 消耗品。
3. 在资产列表或详情里改次数、频率、估值。
4. 消耗品用完点「用完了」，周期从预估变成实测。
5. 到「变化」看自己变好了还是变差了，以及为什么。
6. 换机器时，在「设定」批量导入以前的 JSON。不提供批量导出。

本地开发默认：[http://localhost:2888](http://localhost:2888)
