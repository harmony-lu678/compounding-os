# Personal Compounding OS — 产品规划 v0.2

> 每天让你看到：你正在如何使用已有的一切，以及你的长期生活是否正在变得更好。

- 状态：2026-08-21 按「精简 + 高频化」落地主路径
- 配套：v0.1 规划与架构仍是计算引擎依据；本文件约束**用户可见 IA**

## 1. 产品重心

从 Asset Management 转为 Personal Feedback Loop：

```text
今天发生了什么？
→ 我的资产状态发生了什么？
→ 我最近变好还是变差？
→ 我下一步有什么值得关注？
```

**砍功能，不砍能力。** 四象限、分布、全周期成本等留在详情 / 计算层，不进主路径。

## 2. 一级页面（仅三页）

| 页面 | 回答 | 主内容 |
| --- | --- | --- |
| Today `/` | 今天有什么变化？ | 今日状态（3 指标）/ 最近 7 天 / 今日发现 / 买了·用完了·处置了·校准 |
| Assets `/assets` | 我拥有的东西现在怎么样？ | 总资产 + 今日成本；名称 + 核心成本 + 状态 |
| 变化 `/review` | 这段时间，你有什么变化？ | 主结论 + 值得注意 + 时间线 + 接下来；7D 事件 / 30D 变化 / 90D 趋势 |

设定藏在右上角 / 侧栏底部。`/weekly` 重定向到 `/review`。

变化页不再堆指标卡。结构是：本周期主结论 → 值得注意 → 关键变化（证明）→ 最近发生 → 接下来。7 天看事件，30 天看变化，90 天看趋势。主结论按数据动态挑选，不写死同一句话。

资产详情压成 5 块：当前状态（一个动作）→ 核心指标 → 使用计划 → 系统学到了什么。校准统一写成观察事件，再更新假设与预测。补货是可学习行为，不是跳转到购买表单而已。

## 3. 一级指标（最多 5 个）

资产价值、持有成本、使用效率、资产变化、长期变化。其余进详情假设。

## 4. 使用事件（不是打卡）

原则：**日常资产自动算，低频资产随手记，有规律的资产事后校准。**

详见 [记录模式](./capture_mode.md)。Today 增加「特别使用」：一键 +1、连点、批量完成今天、月度校准。手机/电脑/水杯不出现在待记录列表。

## 5. 季节资产

日期 + 历史使用，预测「此刻该用却没用」的非日常资产。休眠 ≠ 闲置。季节模块并进 Today「特别使用」，不单独占卡。过季日常资产（如夏天的大豆被）不进自动估算名单。详见 [季节资产](./seasonal_assets.md)。

## 6. 明确不做（本轮）

独立能力中心、完整金融资产、Goal、年报独立入口、AI Agent、多端。

北极星改为：**30-Day Active Reflection**——30 天里有多少天愿意打开 Today 看自己的变化。
