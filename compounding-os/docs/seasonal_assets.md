# 季节资产（v0.2）

> 不是催你记录，而是发现你与已经拥有的东西之间正在发生什么。

第一版只用 **日期 + 月份 + 历史使用**。不接天气，不做全量闲置轰炸。

Today 上不单独占一张卡。季节提示并进「今天有没有特别使用？」：可能用到的资产变成快捷按钮，该用却还没对上节奏的才展开关注。变化页把季节滞后、即将进入窗口的资产放进「值得注意 / 接下来」。

过季的「日常资产」（如夏天的大豆被）不出现在自动估算名单里，只留在「其他」里，真用到还能记。

## 两个子能力

- **季节资产**：最近可能会用什么？
- **闲置雷达**：哪些资产不符合你的历史使用节奏？

## 规则

1. 每件耐用品有季节性：全年 / 春秋 / 夏 / 冬 / 特定场景。系统按名称推断，详情页可改。
2. 只在 **Expected Usage Window** 内提醒。8 月的羽绒服是**休眠**，不是闲置。
3. 只有「去年同期在用、今年窗口内明显落后」才进雷达。
4. 场景资产（相机、行李箱）只在「去年这个月用过」时进入观察。

天气和出差/健身场景留给 v0.3 / v0.4。
